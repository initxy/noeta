Persist a named memory as a markdown file (reusing a name overwrites it). Names must be slugs (letters, digits, '.', '_', '-'; no path separators; max 128 chars). Optional 'description' (a one-line summary shown in the memory index) and 'type' (one of: user, project, procedural, reference) are stored as frontmatter — pass them as parameters instead of writing a frontmatter block yourself. Without a description the first non-empty body line becomes the index summary. Writes are confined to the memory directory.

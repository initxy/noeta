Persist a named memory as a markdown file; reusing a name updates that memory, and 'created'/'updated' dates are stamped automatically. Names are slugs (letters, digits, '.', '_', '-'; max 128 chars). Every field follows one rule — omit it to keep what the memory has, pass it empty to remove it, pass a value to replace it — so a rewrite never drops what it does not mention. Frontmatter keys without a parameter of their own ride a leading `---` block in the text under the same rule, and text that is only such a block leaves the body as it is. If the result lists similar existing memories, update one of those instead of keeping a near-duplicate.

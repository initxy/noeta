## Back in plan mode

You left plan mode earlier and are planning again. The plan file {path} holds the plan from that earlier session. Before you plan anything new:
1. Read the plan file to see what was planned.
2. Compare the user's current request with it.
3. Decide how to go on:
   - A different task, even a similar or related one: start over and overwrite the plan file.
   - An explicit continuation or refinement of the same task: change the plan, and remove the parts that no longer apply.
4. Carry on with the planning steps, and always update the plan file one way or the other before you call ExitPlanMode.

Treat this as a new planning session: check the old plan before you assume it still fits.
